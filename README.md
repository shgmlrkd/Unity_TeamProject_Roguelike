# Enter The Dungeon

## 📖 게임 소개

**Enter The Dungeon**은 랜덤으로 생성되는 방을 탐험하며 몬스터를 처치하고, 아이템을 획득해 성장하는 **2D 로그라이크 게임**입니다.

플레이어는 각 방을 클리어하며 다음 맵으로 이동하고, 최종적으로 **보스 방에 도달하여 보스를 처치하는 것**을 목표로 합니다.

---

# 조작 방법

| 기능 | 키 |
|------|----|
| 이동 | **W / A / S / D** |
| 공격 | **마우스 좌클릭** |
| 문 상호작용 / 이동 | **E** |
| 옵션 창 열기 | **ESC** |

---

# 게임 진행

- 문 앞에서 **E키**를 눌러 상호작용하면 다음 방으로 이동합니다.
- 플레이 중 **몬스터가 등장하지 않는 방**이 나올 수 있습니다.
  - 이 경우 다른 방으로 이동하면 몬스터가 등장하는 방 또는 보스 방으로 이동할 수 있습니다.
- 방어구는 아래 조건에서만 새로 획득할 수 있습니다.
  - 현재 장착한 방어구보다 **더 높은 티어의 방어구**를 획득한 경우
  - 또는 **흰색 하트를 모두 소진한 경우**

---

# 골드 사용처

## 1. 보너스룸

- 입장 시 **20 ~ 60 골드**가 랜덤으로 소모됩니다.
- 보너스룸에는 **몬스터가 등장하지 않습니다.**
- 보상을 획득한 뒤 바로 다음 방으로 이동할 수 있습니다.

## 2. 이스터에그 맵 (묘비)

- 묘비 앞에서 **E키**를 눌러 상호작용할 수 있습니다.
- **77 골드**를 사용하면 **히든 무기**를 획득할 수 있습니다.

---

# 몬스터 스폰

- 각 방마다 **최대 스폰 수**가 랜덤하게 결정됩니다.
- 일정 수 이상의 몬스터를 처치하면 최대 스폰 수에 도달할 때까지 추가 몬스터가 생성됩니다.

---

# 권장 사운드 설정

효과음이 다소 작게 들릴 수 있으므로 아래 설정을 권장합니다.

| 항목 | 권장 수치 |
|------|----------|
| 마스터 | **15** |
| 배경음(BGM) | **30** |
| 효과음(SFX) | **30** |

---

# 게임 종료

## 게임 결과 패널 등장

다음 상황에서 게임 결과 패널이 표시됩니다.

- 플레이어가 사망했을 때
- 보스를 처치했을 때

## 게임 결과 패널 구성

- 플레이 타임
- 보스 토벌 여부
- 일반 몬스터 처치 수
- 다시하기 버튼
- 메인 메뉴 버튼
- 게임 종료 버튼
